# 工作区、任务与 CLI 会话

Android 与 Web 共用 `workspaceTaskId`，任务是工作区内的逻辑分组，不是磁盘目录。

## 操作

- 会话树“新建任务”：任务名称和首个会话提示词分开填写；可“启动会话”或“仅建分组”。默认共用工作目录，只有高级选项显式开启 worktree 才建立隔离目录。
- 已有工作目录复用对应工作区；新目录登记为工作区。名称相同的任务仍是独立分组。
- 未完成的空任务、未命名任务和空工作区保持可见。已完成任务及其会话从侧边栏目录树隐藏，但保留在看板和历史中；重新打开任务后恢复显示。旧未分组会话不自动生成任务。
- 会话树、任务详情的会话菜单，以及看板详情的会话移动按钮，共用可搜索目标弹层。选择目标后需确认；当前任务不可选，同名目标显示短 ID。
- `POST /api/workspace-tasks/:taskId/sessions { sessionId }` 只更改归属，不发送新 cwd、不复制会话、不重启 CLI。原目录与历史保持不变；跨工作区移动同样如此。
- 尚不支持该接口的旧服务端会明确报错，不在本地伪造移动成功。

## 同步与导航

- 每个 `WandApi` 实例独立发布写入成功事件；失败和布局保存不触发层级刷新。
- 会话树、看板与任务详情订阅事件；轮询补齐其他客户端的修改。看板和详情仅在前台生命周期中轮询。
- 任务详情静默刷新保留选中项与正在填写的创建弹层，不闪 Loading；移动后清除源任务中已不存在的会话项。
- 打开看板会话时携带真实工作区/任务 ID；移动与改名后更新导航元数据，不替换会话 ID。
- 首个会话启动失败时，保留已经创建的任务并明确提示；任务不会因重试而被悄悄复制。

## 验证

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

回归覆盖提示词的 structured/PTY 请求字段、独占移动请求和失败事件、任务身份解析、同名/空任务、导航归属更新，以及详情刷新不打断创建表单。

模拟器验收：在隔离服务端上从会话树新建任务和 Shell，从看板新建空任务；三个入口移动并核对 session ID、cwd、startedAt 不变；其他客户端改名可自动同步，重装后归属仍保留。检查 320dp 窄屏与输入法弹出时的搜索、可滚动目标列表和固定确认按钮。没有物理真机参与本轮验收。
